- BLE/demo transports live in src/lib/transport.ts and protocol parsing in src/lib/smartcity.ts; UI only calls Transport.send so demo and real device stay interchangeable.
- Service worker is generated by vite-plugin-pwa and registered only via src/lib/sw-register.ts (guarded against dev/preview) to avoid stale preview caches.
- Transport emits optional diagnostic and error callbacks; testing panels consume these instead of accessing Bluetooth directly, so device checks remain authoritative and demo checks stay explicitly simulated.
- The root-mounted install notice captures browser install events before the splash finishes, with session-scoped dismissal and manual installation fallback because browser support varies.
- Keep user-supplied interactive models in sandboxed pages; parent-page controls use a narrow, versioned message contract so the dashboard can integrate safely without exposing model internals.
- Keep troubleshooting report assembly as a pure helper alongside recovery guidance so report contents can be tested independently of browser downloads.
- Serve user-provided firmware as an unchanged static source file and use that same file for viewing, copying, and downloading so its bytes and line endings remain intact.
